## Status rules

- `VERIFIED` requires matching source and runtime evidence for the stated scope.
- `SOURCE_VERIFIED` means source exists but runtime evidence is incomplete.
- `PARTIAL` means a meaningful subset passed while required steps remain open.
- `NOT_IMPLEMENTED` is used when the current product path is incomplete.
- `UNVERIFIED` means evidence is insufficient; it is not a production claim.
